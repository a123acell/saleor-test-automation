# Apifox 导入说明

本目录提供两份文件，导入 Apifox 后即可直接调试 Saleor 的全部核心接口。

| 文件 | 用途 |
| --- | --- |
| `saleor-graphql.postman_collection.json` | 接口集合，19 个请求，按业务模块分 6 个文件夹 |
| `../schema/saleor_schema.graphql` | 完整 GraphQL schema（SDL），用于开启字段自动补全 |

---

## 一、导入接口集合（必做）

1. 打开 Apifox，登录后进入任意项目（没有就新建一个）
2. 左侧菜单找到 **项目设置** → **导入数据**
3. 选择 **Postman** 标签
4. 把 `saleor-graphql.postman_collection.json` 拖进去（或点「选择文件」）
5. 导入模式选 **智能合并**（首次导入用「覆盖」也可以）
6. 点 **确认导入**

导入后左侧会出现 6 个文件夹：

```
01 鉴权
02 商品
03 核心链路 · 购物车到下单
04 订单
05 账户
06 购物车扩展操作
```

---

## 二、配置环境变量

导入后集合已自带变量，**默认值可直接用**。如需改动，在 **环境管理** 里新增一个环境，配置：

| 变量名 | 默认值 | 说明 |
| --- | --- | --- |
| `baseUrl` | `http://localhost:8000` | Saleor 地址 |
| `token` | 空 | 登录后自动写入 |
| `refreshToken` | 空 | 登录后自动写入 |
| `variantId` | 空 | 查商品列表后自动写入 |
| `checkoutId` | 空 | 创建购物车后自动写入 |
| `checkoutToken` | 空 | 创建购物车后自动写入 |
| `checkoutTotal` | 空 | 创建购物车/查详情/选配送后自动刷新 |
| `lineId` | 空 | 查购物车详情后自动写入 |
| `shippingMethodId` | 空 | 查购物车详情后自动写入 |
| `orderId` | 空 | 完成下单后自动写入 |
| `registerEmail` | 空 | 注册请求的预请求脚本自动生成 |

> 除 `baseUrl` 外都不需要手工填，请求里挂了测试脚本会自动回写。

---

## 三、怎么跑通一次完整下单

按文件夹编号顺序执行即可，**不要跳步**：

```
01 鉴权  →  执行「01 登录获取 Token」      （拿到 token）
02 商品  →  执行「05 商品列表（分页）」     （拿到 variantId）
03 核心链路  →  07 → 08 → 09 → 10 → 11 → 12 → 13  （按编号顺序全跑）
```

跑完「13 完成下单」就能拿到订单号。

**注意顺序上的两个硬约束：**

- 「10 查询购物车详情」必须在「08 填写收货地址」之后 —— 没填收货地址，`availableShippingMethods` 是空数组
- 「12 创建支付」的金额用的是变量 `checkoutTotal`，由「11 选择配送方式」自动刷新 —— 运费会计入总额，所以顺序不能颠倒

---

## 四、开启字段自动补全（推荐）

Apifox 支持挂载 GraphQL schema 做字段提示，写 query 时不用背字段名：

1. **项目设置** → **GraphQL** → 上传 schema 文件
2. 选择 `../schema/saleor_schema.graphql`
3. 之后在请求的 Body（GraphQL 模式）里编辑时，输入字段会有自动补全

> schema 文件约 1MB、1475 个类型，首次解析稍慢，属正常。

## 五、常见问题

**Q：执行后返回 200 但没数据，或报「Cannot query field」**
A：说明查询语句里的字段名在该版本不存在。以 `../docs/接口清单.md` 里的实际签名为准。

**Q：下单报 `CHECKOUT_NOT_FULLY_PAID`**
A：支付没创建，或金额小于应付总额。检查「12 创建支付」是否执行成功。

**Q：下单报 `SHIPPING_METHOD_NOT_SET`**
A：「11 选择配送方式」没执行或失败，`shippingMethodId` 为空。

**Q：`token` 变量一直是空**
A：先执行「01 登录获取 Token」，它的测试脚本才会写入 token。检查脚本是否被禁用。

**Q：想重复执行整套流程**
A：可以直接重跑，每次「07 创建购物车」都会生成新的购物车，互不干扰。注册接口的邮箱由预请求脚本随机生成，也不会重复。
